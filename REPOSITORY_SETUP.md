## Recommended GitHub settings

### General

- Enable Issues.
- Enable Discussions only if the project will have a community around it.
- Disable unused project features.

### Branches

Protect `main` with:

- Pull request required before merge.
- Required CI checks.
- Block force pushes.

### Security

Enable Dependabot alerts and security updates.

### About section

Use the repository description above and add the topics from this file.

### Social preview

Create a 1280×640 preview image using the same dark background, warm orange `7`, and the text:

```text

Track every roll. See the probability.
```
