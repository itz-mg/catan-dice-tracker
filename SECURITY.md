# Security & Privacy

## Privacy model

Catan Dice Tracker is local-first.

Core game information is stored on-device using IndexedDB. Preferences are stored in localStorage.

The application does not require:

- accounts
- passwords
- a backend
- cloud game storage
- analytics for core functionality

## Reporting a vulnerability

Please avoid publishing sensitive vulnerability details in a public issue.

Use GitHub's private security reporting mechanism when enabled for the repository, or contact the project maintainer directly.

Include:

- affected version or commit
- reproduction steps
- expected behavior
- actual behavior
- relevant logs or screenshots

Do not include secrets or personal data in reports.
